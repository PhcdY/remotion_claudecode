## 2. Bẫy thi (mỗi mục cần một hình riêng, xem hoa.md › 6.7)
- **Tên gọi chéo**: chất khử ↔ *bị* oxi hoá ↔ quá trình oxi hoá; chất oxi hoá ↔ *bị* khử ↔ quá trình khử. Câu nhớ: "Khử cho – O nhận", "chất khử: số oxi hoá tăng". → hình: `RedoxRoleTable`.
- **Số oxi hoá ≠ cách viết điện tích ion**: số oxi hoá viết $+2$ (dấu trước), điện tích ion viết $\ce{Cu^2+}$ (dấu sau).
- **Electron nhường = electron nhận**: đây là chỗ dựa để cân bằng phương trình. → hình: `ElectronBalance`.
- **Ion không đổi**: trong $\ce{Fe + CuSO4 -> FeSO4 + Cu}$, nhóm $\ce{SO4^2-}$ giữ nguyên số oxi hoá (S +6, O −2) — không phải chất khử hay chất oxi hoá.
- (Chỉ nêu nếu người dùng duyệt) Ngoại lệ: H là −1 trong hydride kim loại ($\ce{NaH}$); O là −1 trong peroxide ($\ce{H2O2}$).

## 3. Ví dụ đã kiểm số (dùng nguyên, không tự đổi)
| Loại | Chất | Số oxi hoá | Phép kiểm |
|---|---|---|---|
| Đơn chất | $\ce{Na}$, $\ce{Fe}$, $\ce{O2}$, $\ce{Cl2}$ | 0 | — |
| Phân tử | $\ce{H2O}$ | H +1, O −2 | 2·(+1) + (−2) = 0 |
| Phân tử | $\ce{NaCl}$ | Na +1, Cl −1 | (+1) + (−1) = 0 |
| Phân tử | $\ce{H2SO4}$ | H +1, S +6, O −2 | 2·(+1) + (+6) + 4·(−2) = 0 |
| Phân tử | $\ce{Fe2O3}$ | Fe +3, O −2 | 2·(+3) + 3·(−2) = 0 |
| Ion đơn | $\ce{Cu^2+}$, $\ce{Fe^2+}$ | +2 | bằng điện tích |
| Ion đa | $\ce{SO4^2-}$ | S +6, O −2 | (+6) + 4·(−2) = −2 |
| Ion đa | $\ce{NH4+}$ | N −3, H +1 | (−3) + 4·(+1) = +1 |
| Phản ứng | $\ce{Fe + CuSO4 -> FeSO4 + Cu}$ | Fe 0 → +2 (nhường 2e); Cu +2 → 0 (nhận 2e) | 2 = 2 |
| Cân bằng | $\ce{Fe2O3 + 3CO -> 2Fe + 3CO2}$ | Fe +3 → 0 (nhận 3e, ×2 = 6e); C +2 → +4 (nhường 2e, ×3 = 6e) | 6 = 6 |

`OxidationFormula` tự cộng và báo lỗi nếu tổng sai — luôn dựng ví dụ bằng component này.
